# 🎓 Online Course Analytics Dashboard

An interactive, data-driven dashboard built to analyze and explore online course trends across major platforms like **Udemy** and **Coursera**. 

## 🔍 Project Overview
This project focuses on the end-to-end data pipeline—from automated web scraping to interactive visualization. It allows users to gain insights into the competitive landscape of online education, comparing pricing, ratings, and content duration across platforms.

### What this project does:
* **Data Collection:** Scrapes real-time course data (titles, ratings, prices, duration, etc.).
* **Large Scale Dataset:** Collected nearly 10,000 course records from multiple platforms.
* **Data Engineering:** Cleans, preprocesses, and merges disparate datasets for unified analysis.
* **Exploratory Data Analysis (EDA):** Extracts meaningful trends and platform benchmarks.
* **Interactive UI:** Provides a user-friendly interface for searching and filtering courses.

## 📊 Key Features
- **Platform Comparison:** Side-by-side analysis of Udemy vs. Coursera.
- **Quality Metrics:** Identification of top-reviewed and highest-rated courses.
- **Pricing Strategy:** Detailed analysis of price distribution and course duration.
- **Live Filters:** Interactive dashboard with dynamic search and filtering capabilities.

## 💡 Tech Stack
- **Language:** Python
- **Libraries:** Pandas (Data Manipulation), Matplotlib & Seaborn (Visualization)
- **Scraping:** Selenium
- **Web Framework:** Streamlit (Dashboard UI)
